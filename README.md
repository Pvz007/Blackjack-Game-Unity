# Blackjack Game in Unity

## Overview

A 2D Blackjack game developed in Unity using C#. The project simulates a classic casino Blackjack experience with dealer AI, card animations, score tracking and chip management.

## Features

- Standard Blackjack rules
- Dealer AI
- Hidden dealer card
- Hit / Stand gameplay
- Automatic deck shuffling
- Chip system
- Dealer chip tracking
- Statistics panel
- Round system
- Card counter
- Blackjack detection
- Bust detection

## Technologies

- Unity
- C#
- TextMeshPro

## How to Run

1. Clone the repository.
2. Open the project using Unity Hub.
3. Open the main scene.
4. Press Play.
